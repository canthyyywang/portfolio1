# 王启萌 · 个人作品集

资深 AI 产品体验架构师个人作品集网站。Next.js (App Router) + Tailwind CSS，极简科技风。

## 开发

```bash
npm install
npm run dev
```

浏览器打开 [http://localhost:3000](http://localhost:3000)。

## 构建

```bash
npm run build
npm start
```

## 页面结构

- **首页** `/`：首屏 Hero + 项目导航区（3 张卡片）
- **项目页** `/project-ai-platform`、`/project-ai-agent`、`/project-efficiency`：案例详情（可后续补充内容）

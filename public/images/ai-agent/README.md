# 智能化 Chat 组件库 · 图片占位

将以下图片放入本目录后，项目页会自动展示，未放入时显示占位。

| 文件名（扩展名可改为 .png / .webp） | 说明 |
|--------|------|
| `architecture-diagram.jpg` | 组件体系架构图示 (Standard vs Extension) |
| `fullscreen-layout.jpg` | 全屏布局示例 |
| `sidebar-layout.jpg` | Sidebar 侧边助手布局示例 |

支持格式：jpg, jpeg, png, webp。若使用 .png 或 .webp，把页面代码里对应 `src` 的扩展名改成一致即可。
